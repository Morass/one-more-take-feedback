# One More Take: feedback

**One More Take** is a puzzle game by Morass: you edit the film of a doomed stunt scene until the heroine walks away.

Found a problem, or have an idea? [Open an issue](../../issues/new/choose).

It helps to say which platform you played on (Android, Windows, macOS), the scene's title, and what you did just before it went wrong. A screenshot is welcome.
